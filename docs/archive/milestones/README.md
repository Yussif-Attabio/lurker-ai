# Milestone archive

These files document the build process from M1 through M6: implementation
plans, owner decisions, preflights, recovery plans, and chronological notes.
They are retained for auditability but are not required to run Lurker AI.

Current submission-facing documentation remains at the repository root:

- `README.md`
- `BUILDER_CENTER_ARTICLE.md`
- `DEMO_SCRIPT.md`
- `EVALUATION_ACCEPTANCE.md`
- `RELIABILITY_ACCEPTANCE.md`
- `SUBMISSION_ACCEPTANCE.md`

The `M` prefix means **milestone**. It was useful while the prototype was built,
but keeping superseded milestone documents in this archive prevents them from
obscuring the application source and current submission materials.
